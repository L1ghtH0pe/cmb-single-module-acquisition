# CMB 探测器多通道实时数据采集系统

C++ / Linux / TCP/IP / 多线程

**项目描述**：面向 CMB 探测器阵列多通道实时数据采集需求，设计并实现高速数据获取系统。下位机以 200 Hz 打包 1704 通道复数采样数据，经 SFP+ 光纤链路以 TCP 传输至上位机；上位机负责实时接收、完整性校验和存储，支持 10 路以上模块并发采集。

**技术实现**：每个模块使用独立的 TCP 长连接，开启 TCP_NODELAY 以降低发送延迟；接收端循环调用 recv() 按帧长组帧，解决粘包和半包问题。接收端分为采集线程和存储线程，两者通过基于 std::atomic 的 SPSC 无锁环形缓冲区传递数据，缓冲区预分配，避免磁盘 I/O 影响实时接收。发送端基于 sleep_until 按绝对时间触发 200 Hz 周期任务，消除累积漂移。通信协议采用定长二进制帧，帧头和数据各带一个 CRC-32 校验。实测连续传输 12 万帧，零丢帧、零误码。
